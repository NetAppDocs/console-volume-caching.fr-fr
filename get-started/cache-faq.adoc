= Questions fréquentes concernant la mise en cache volumétrique
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Cette FAQ peut vous aider si vous cherchez simplement une réponse rapide à une question.

*Quelle est l'URL de mise en cache des volumes ?* Pour l'URL, dans un navigateur, saisissez : https://console.netapp.com/["https://console.netapp.com/"^] pour accéder à la console BlueXP .

*Avez-vous besoin d'une licence pour utiliser la mise en cache volumétrique ?* Un fichier de licence NetApp (NLF) n'est pas requis.

*Comment activer la mise en cache des volumes ?* La mise en cache des volumes ne nécessite aucune activation. L'option de mise en cache des volumes apparaît automatiquement dans le menu de navigation de gauche de la NetApp Console .
