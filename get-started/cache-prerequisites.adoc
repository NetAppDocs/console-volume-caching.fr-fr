= Prérequis pour NetApp Volume Caching
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Commencez par vérifier l’état de préparation de votre environnement opérationnel, de votre connexion, de votre accès réseau et de votre navigateur Web.

Pour utiliser la mise en cache volumétrique, vous devez vous assurer que votre environnement répond à toutes les exigences.

* ONTAP 9.8 et versions ultérieures
+
** Autorisations d'administrateur de cluster ONTAP
** LIF intercluster sur les clusters


* Dans la NetApp Console:
+
** Le Console agent doit être configuré dans la NetApp Console. Tous les clusters source et cible doivent être sur le même Console agent. Reportez-vous à la link:https://docs.netapp.com/us-en/console-setup-admin/task-quick-start-standard-mode.html["Flux de travail de démarrage pour NetApp Console"^]documentationlink:https://docs.netapp.com/us-en/console-setup-admin/concept-agents.html["En savoir plus sur les agents de console"^].
** L'environnement de travail doit être aménagé.
** Les clusters doivent être ajoutés dans l'environnement de travail cible et dans un état ON ou dégradé.
** Configuration requise pour la NetApp Console standard. Se référer à https://docs.netapp.com/us-en/cloud-manager-setup-admin/reference-checklist-cm.html["Configuration requise NetApp Console"^] .
